# Los Jardines de la Alhambra

Proyecto Java de práctica del ciclo DAW (Maven) con las clases `Jardines_Bonito` y `Jardines_Juez`, su clase de pruebas unitarias y la documentación Javadoc generada.

## Contenido

- `src/main/java/org/example/`: código fuente.
- `src/test/java/org/example/`: pruebas unitarias.
- `index.html`, `org/`, `allclasses-index.html`...: documentación Javadoc generada (se puede abrir en el navegador).

## Requisitos

- JDK 25 y Maven (o IntelliJ IDEA, que los incluye).

## Cómo ejecutarlo

```bash
mvn compile
mvn test      # si el proyecto incluye pruebas
```

## Estado

Proyecto de aprendizaje. La clase `Main` está vacía: el código se usa a través de las pruebas.
